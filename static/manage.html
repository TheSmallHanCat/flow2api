Import accounts

Accepts account JSON exported by this system, a browser cookie export for one account (array), or a {"cookies": [...]} file. Up to 100 accounts per import.

Format: Each item must include google_cookies. login_account is optional; if omitted, the Flow login email is read from cookies. Existing accounts are updated and others are added. Legacy access_token and session_token formats are no longer supported.

Exported files contain cookies that can sign in to Flow directly. Store and import them only on trusted devices.
